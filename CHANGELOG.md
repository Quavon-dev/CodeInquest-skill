# Changelog

All notable changes to CodeInquest are documented here.

## Unreleased

## 0.1.0 — 2026-08-10

### Added

- Initial CodeInquest repository-wide audit skill.
- Accountable coverage ledger and complete/partial/failed coverage states.
- Multi-agent review orchestration and independent high-risk review rules.
- Comprehensive security, identity, payments, accounting, correctness, performance, infrastructure, AI-agent, and code-reduction review matrix.
- Evidence-driven finding format with validation, counterevidence, attack-path, severity, and proof-gap requirements.
- Read-only audit mode with explicit Fix Mode integration guidance for CodeCanon.
- Installation commands and AI-assisted installation prompt.
